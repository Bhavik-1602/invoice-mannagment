# Design System

## Style
- Clean
- Professional
- Business-focused
- Minimal animations
- Print-friendly

## Typography
Font: Inter (Google Fonts)

## Colors
- Primary: #1E40AF (Professional Blue)
- Primary Light: #3B82F6
- Background: #F8FAFC
- Surface: #FFFFFF
- Text Primary: #0F172A
- Text Secondary: #475569
- Text Muted: #94A3B8
- Border: #E2E8F0
- Success: #16A34A
- Warning: #D97706
- Error: #DC2626
- Accent: #1E40AF

## Layout
- Left sidebar navigation (desktop)
- Collapsible sidebar (tablet)
- Drawer menu (mobile)
- Clean white content area

## Components
- Cards with subtle shadows
- Clean form inputs with labels
- Professional tables
- Confirmation modals for destructive actions

## UX Requirements
- Large readable fields
- Clear labels
- Prominent action buttons
- Loading states
- Error messages
- Success confirmations
- Mobile responsive
